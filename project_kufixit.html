เกี่ยวกับโปรเจกต์

KU FixIt เป็นเว็บแอปพลิเคชันที่ออกแบบมาเพื่อแก้ไขปัญหาความล่าช้าและความยุ่งยากในการแจ้งซ่อมแซมสาธารณูปโภคภายในหอพักนักศึกษา ระบบนี้ช่วยให้นิสิตสามารถส่งคำร้องแจ้งซ่อม (เช่น ประปา, ไฟฟ้า, แอร์) ได้อย่างง่ายดาย พร้อมทั้งสามารถติดตามสถานะการดำเนินงานได้แบบ Real-time

ตัวระบบถูกออกแบบ UI/UX ผ่าน Figma ให้มีความใช้งานง่าย สบายตา และแบ่งสิทธิการใช้งานออกเป็น 3 ระดับ เพื่อให้การบริหารจัดการงานซ่อมบำรุงของทางหอพักเป็นไปอย่างมีประสิทธิภาพสูงสุด

ฟีเจอร์หลัก (Key Features)

  • Role-Based Access Control: ระบบแบ่งผู้ใช้งานเป็น 3 ระดับ (นิสิตผู้แจ้ง, ช่างซ่อม, ผู้ดูแลระบบ/Admin)
  • Ticket System: สร้างใบแจ้งซ่อม ระบุหมวดหมู่ปัญหา อาคาร ห้อง และแนบรูปภาพประกอบได้
  • Status Tracking: ติดตามสถานะงานซ่อมแบบไทม์ไลน์ (รอดำเนินการ -> กำลังซ่อม -> เสร็จสิ้น)
  • Admin Dashboard: หน้าสรุปสถิติงานซ่อมทั้งหมดสำหรับผู้ดูแล และระบบเลื่อนสถานะ/จัดการผู้ใช้
  • Responsive Design: รองรับการใช้งานทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ
