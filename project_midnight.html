About the Game

Midnight is an exciting and challenging 3D Obstacle Course (Obby) game created using the Unity Engine. Set against a beautiful and mysterious midnight sky, players must test their precision and timing to jump, dodge, and navigate through floating platforms to reach the finish line.

The game was designed to provide a fun, fast-paced platforming experience, focusing on player movement mechanics, level design, and atmospheric aesthetics.

Key Features

  • Smooth 3D platforming and character movement controls.
  • Progressively difficult obstacle courses and traps.
  • Atmospheric "Midnight" theme with custom lighting and skyboxes.
  • Built entirely in Unity utilizing C# scripting.
