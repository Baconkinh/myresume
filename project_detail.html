About the Game

Tournament of 5 Hearts is a retro-inspired, turn-based RPG built entirely in Java using the FXGL engine. Dive into a beautifully pixelated world where you must gather the fragments of the five legendary hearts to restore balance to the realm.

Engage in strategic, classic turn-based combat. Build your party, manage your resources carefully, and exploit enemy weaknesses. With custom character creation, you can tailor your heroes to fit your playstyle.

Features

  • Classic turn-based RPG combat system.
  • Custom character creation with unique stats and abilities.
  • Charming pixel-art aesthetic and atmospheric soundtrack.
  • Built from scratch using Java and FXGL.
